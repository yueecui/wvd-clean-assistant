# WVD 装备清理助手

给《Wizardy Daphne》用的桌面辅助工具：**截图识别装备 → 主数据校验 → 自定义规则评分 → 批量自动处理**。

只读游戏画面，不注入、不挂钩、不改游戏内存。跑在 MuMu 模拟器上，通过自带 adb 截图与点击。

## 它能做什么

### 1. 装备梳理

- **自动扫描**：在游戏的装备列表界面点「开始扫描」，逐件点开详情 → OCR 识别 → 自动滚动 → 到底自动停。
  采集名称、强化、星级、附加加护、锁定、阶、类型等字段，458 件实测 1.5～2.5 秒/件。
- **名称校准**：游戏字体模糊，OCR 常认错字（如「踉跄凉鞋」读成「跟跑凉鞋」）。用解包主数据校验，
  认不准的给出相似候选，人工选一次后全局生效，不用反复纠正。
- **自定义评分**：可视化编辑规则——按强化 / 阶级 / 星级 / 装备类型 / 属性组合打分，改动即时重算全部结果。
  选中规则先于按类型的规则，同范围按优先级匹配。
- **结果与导出**：按评分排序挑装备，过滤器状态自动记住，一键导出 CSV（utf-8-sig，Excel 直接打开）。

### 2. 自动处理

| 功能 | 作用 | 前提 |
|---|---|---|
| 强化白装 | 白色装备逐件强化到 +5 | 铁匠铺「装备强化」→ 持有一览，筛出白装 |
| 改造绿装 | 扫描改造石素材，按配置的属性自动改造 | 游戏内改造界面，先扫描素材 |
| 自动提炼 | 批量提炼，自动关弹窗，统计下级/全改造石 | 铁匠铺「提炼」，配好过滤器 |
| 自动出售 | 批量出售，统计金币 | 道具店「出售」，配好过滤器 |

提炼/出售支持**日志累加**：中途停止后可从当前日志继续，件数、金币、批号接着算，进程重启不丢。

### 3. 自动更新

- 顶栏「更新」按钮检查新版本，**程序**和**游戏资源**两条通道独立。
- 游戏客户端更新后，维护者用 `update_resources.bat` 从解包目录同步新 icon / 主数据到仓库；
  用户点「更新资源」即可增量拉取，不用换 exe。
- 代码发版由 GitHub Actions 自动打包、发布 Release；用户点「下载新版程序」→「重启完成更新」，
  个人配置和扫描结果全部保留。
- 默认不联网，只有点「更新」时才检查一次。

## 快速开始

### 绿色版（推荐）

从 GitHub Releases 下载最新 zip，解压后双击 `wvd-clean.exe`，浏览器会自动打开 `http://127.0.0.1:23333/`。
确保 MuMu 模拟器已运行游戏，adb 会自动探测；探测不到可在界面里手动指定路径。

### 源码运行（开发）

需要 Python 3.11+ 和 MuMu 模拟器：

```powershell
pip install -r requirements.txt
python app\main.py        # http://127.0.0.1:23456/
```

前后端分开开发时，改前端不用重新打包：

```powershell
# 终端 1
$env:WVD_NO_BROWSER=1; python app\main.py
# 终端 2
cd web; pnpm install; pnpm dev      # http://127.0.0.1:5173/，保存即生效
```

要在后端端口直接访问或打绿色版时才需要 `cd web; pnpm build`。

### 使用流程

1. MuMu 进入带装备列表的界面（如铁匠铺「装备强化」）。
2. 点「▶ 开始扫描」，脚本自动逐件识别、滚动、到底停止。
3.「待确认」里处理识别不准的条目（校准一次永久生效）。
4. 在「评分规则」页配好规则，回扫描页按评分排序，导出 CSV。

## 项目结构速览

```
app/           Python 后端与扫描逻辑（main / master / match / rules / scan / parse / update ...）
web/           Vue3 + TS + TailwindCSS4 + Vite8 前端
masterdata/    入仓的游戏主数据（4 个 json）
icons/         入仓的装备图标（792 张）
tools/         发布脚本（生成 manifest、资源同步 CLI）
manifest.json  版本清单（程序 + 资源哈希），脚本生成
update_resources.bat  从本地解包目录同步资源进项目
build.bat      打包绿色版到 dist\WvdClean
docs/          功能实现记录、版本更新手册
```
